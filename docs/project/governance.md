## Maintenance status

**Experimental, actively developed.**

CHITCHAT is a research pipeline, not a supported product. It is being worked on
and changes without notice. There is no release cadence, no deprecation policy
and no support commitment. Treat anything here as subject to change.

## Who maintains it

The project is led by researchers at the Laboratory of Intelligent Global
Health & Humanitarian Response Technologies (LiGHT) at EPFL, in collaboration
with the ICRC. The contributor list is on the [About](about.md) page.

Day-to-day maintenance of the pipeline sits with the EPFL team.

## Getting in touch

| I want to... | Do this |
| --- | --- |
| Report a bug | [Open an issue](https://github.com/fiifidawson/CHITCHAT/issues/new) |
| Propose a change | Read [Contributing](contributing.md) first |
| Raise a concern about how the output is being used | See [Limitations & intended use](limitations.md) |
| Report a security or credential issue | Do **not** open a public issue — contact the maintainers directly |

If you are part of the project team, the working channel is on Slack; ask
David, Tim or Fiifi to add you.
