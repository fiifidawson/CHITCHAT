# Modules

The tooling inside CHITCHAT is organised into parts that are useful on their
own, not only inside this project. Paper discovery does not care what happens
to its output; LitLens does not care where its input came from. That
independence is what lets pieces of CHITCHAT be reused in separate
repositories for related work.

!!! warning "These are design specs, not shipped packages"

    `paper_discovery` and `litlens` **do not exist as installable packages
    yet**. The pages below are the specifications for extracting them from
    `legacy/`, written in enough detail to be implemented from. They describe
    the intended API, not the current one.

    The working code is still under `legacy/src/` and `legacy/analysis/`, and
    is documented stage by stage in [The pipeline](../pipeline/index.md).

## On API reference

These pages are written and maintained by hand. There is deliberately no
autogenerated API documentation: the pipeline is not importable as a package
and its docstring coverage is thin, so generated reference would be mostly
empty headings. Once `paper_discovery` and `litlens` exist as real packages
with typed, documented signatures, generating reference from source becomes
worth doing.
