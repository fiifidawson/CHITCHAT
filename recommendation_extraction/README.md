## A 'Ethical Trade-off' first toolkit for Humanitarian AI recommandation

My proposition would be to, rather than doing a check-list approach that risks either not being comprehensive
or being overwhelmingly long, to take a 'toolkit' approach which lets users explore recommendations which are best suited 
for their context/needs. The idea would be to take an 'ethical trade-off' first lense, which, for each high-priority paper
you extracted, looks for such trade-off or tensions and how the authors proposed/recommended to resolve it. 

The intended user journey of this 'exploration tool' would therefore to first ask users to identify the ethical trade-offs their
particular context/use-case entails, and then provide them with a tool to see how they could/should
resolve these trade-off. This could help in ensuring that the essential critical 
thinking phase of developing an AI system in an humanitarian context is not lost,
i.e. the developement team cannot offload their moral thinking into a predefined checklist.

## Dependency
I used uv for dependency management, it will install all the necessary library automatically the first time you call uv run.

## Extract ethical trade-off and associated recommendation
To do this I used gpt5. This has the advantages of being quick, plus this could mean that in the future we may automatically
parse and add recommandation to our database, helping the tool to stay up to date. However, if we want to go down this avenue
we should make sure to thoroughly validate the results. 

To do this extraction I used a similar prompt that the one you curated for the high priority paper identification.
You can find my prompt under `prompts/trade_off_extraction.txt`. The script to perform the extraction is under 
`src/extraction_script.py` and should be called as such:

```uv run src/extraction_script.py --api-key <OpenAI key> --prompt_text_path prompts/trade_off_extraction.txt --output-path ../data/extracted_tradeoffs.csv --classification_path  < path to the classification in high/low priority of the paper, something like classification_data.jsonl> --paper_data_path <path to file with the actual paper text, somethink like obtained_lit.json>```

## Unsupervised Clustering of the ethical-trade off
Now that we have extracted (hopefully) all the ethical trade-offs mentioned in the papers, we can group them together.
I detail my unsupervised approach in the juypter-notebook `notebooks/Unsupervised_Clustering.ipynb`. This asks the output 
of the previous step as input.

## Small Demo
Now that we have a list of (I found around 1000) recommendation, we can make them discoverable to users in some app. 
I made a (very) rough demo which you can find under `src/explorer_app.py` which shows you recommendation based on the 
ethical trade-off you are interested in, but you can also filter by types of harm 
(I used Shelby's taxonomy of algorithmic harms as a reference), or by the stage in the developement phase you are interested in. 

You can run the demo as such:
```uv run streamlit run src/explorer_app.py -- <path to the trade-off data generated by the clustering step>```
